# Native question request HTTP and hook routes

UserQuestionRoutes explicitly mounts list, submit and cancel routes using existing native auth/account storage and input lifecycle services. Real HTTP contracts compare Fastify with Axum, including bearer/cookie auth, deleted users, cross-origin cookie rejection, missing/foreign/unowned requests, repeated query filters, answer object/array normalization, selected string filtering, free-text preservation, exact errors, callbacks, promise results and cancellation.

HookRoutes explicitly mounts secret-authenticated wake/agent endpoints, retaining the shared origin boundary and parser-before-secret ordering. Exact token comparison, event-before-callback ordering, primitive bodies, null/omitted results and error propagation are compared. A typed synchronous emitter borrows the payload so object mutations reach the later callback. Null/missing input has separate empty objects for event and callback because the source evaluates body ?? {} twice. The production HookBus/lifecycle adapter must preserve the borrowed payload contract; this slice supplies the native HTTP adapter and does not activate agent execution.

The shared native JSON parser now rejects recursive __proto__ and constructor.prototype properties, matching Fastify secure-json-parse. It decodes UTF-8 with replacement, strips a leading BOM and uses the source invalid-body response. The original HTTP assertions failed on prototype pollution and null hook-body aliasing before these fixes; restored mutants reproduce both failures. Generic parse and framework limits are focused contracts, not proof of every Fastify parser edge. Native JSON strings accept Unicode scalars; lone-surrogate wire strings and full framework routing/error equivalence remain limitations.

Eleven tests pass, including four bounded reference-driver tests. Three restored mutations remove ownership filtering, nullish-body separation or prototype checking; each fails the original equality assertions. Evidence: question-http-mutations.json, question-http-mutant-*.log and runtime-restored.log under .jait/artifacts/gateway-rust. These are focused component credits; production startup, full streaming and runtime activation remain separately gated.
