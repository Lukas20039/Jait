# Native disk-space watchdog

Reference: `packages/gateway/src/services/disk-space-watchdog.ts`. Native: `services/disk_space_watchdog.rs`. Target: `gateway_rust_watchdog`.

The native policy owns path deduplication, agent-job classification, warning/critical thresholds, per-path alert state and pause decisions. Scheduler and notification adapters are explicit, and no scheduler is activated by constructing the service. Callers supply the state/temp paths; the native filesystem sampler runs statvfs through the shared bounded blocking lane. Closed/overloaded admission fails before OS work.

The real TypeScript watchdog and native policy are exercised with the same disposable scheduler records, ordered notification/update sinks, filesystem samples and clock. Comparisons retain all calls, partial effects and resulting job state. Cases cover every agent-job trigger, disabled/non-agent exclusions, shared-path deduplication, 80%/90% boundaries, inode pressure, project-only and global storage pauses, alert escalation/suppression/recovery, missing remote versus local paths, invalid capacity, nonfinite samples, failed notifications/list/update and preservation of existing input metadata. Recovery never reenables paused jobs. Decimal alert formatting follows ECMAScript toFixed(1), including exact half cases and large magnitudes.

Native integration reads the project filesystem and compares fixed capacity with Node statfs, checks finite returned counters, invokes the bounded adapter and verifies rejection after closing its lane. Free blocks/inodes are not asserted equal across sequential live samples because concurrent filesystem writes can change them. Ten tests pass (six focused tests and four shared driver tests). Three mutations alter the 90% boundary, include non-agent jobs and remove alert deduplication. All fail the unchanged comparisons; restored sources pass. Strict native Clippy passes. Evidence: `.jait/artifacts/gateway-rust/watchdog/`.

Boundary: typed scheduled jobs with string project roots and object/null input metadata; finite JSON and well-formed Unicode. Real sampling is implemented/tested on Unix/Linux; other platforms return an explicit unavailable probe error. Production scheduler-before-tick integration and supported-platform filesystem sampling remain separate work. This library validation pauses no live job and sends no external notification.
